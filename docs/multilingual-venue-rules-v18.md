# 施設ルールの多言語説明（V18・2026-11-09）

> **最新方針：** 2026-11-09の最新ユーザー指示により、モバイルアプリの中国語・韓国語対応を撤去。UI・AI応答・施設ルールの案内は日本語／英語、OCRは日本語／Latinに限定する。中国語・韓国語はポスターの案内で扱う。既存の施設原文・翻訳データを破壊しないため、管理Web・API・共通契約の保存形式は保持する。 以下は追加当時の履歴。[撤去の範囲と検証](app-languages-ja-en.md)。

ユーザー承認した方針「可否・具体的な条件・対象エリアを4言語で理解し、原文も確認できる」に基づく実装。アプリの日本語・英語・簡体字中国語・韓国語表示を、施設登録データと管理APIまでつないだ。管理Webの操作言語は日本語のまま、施設側が多言語説明を登録・確認できるようにした。

## 施設の登録と公開

既存の可否（撮影／SNS公開／商用利用）に、次の定型条件を追加した。条件を選ぶと対応する可否を「条件付き」にする。可否を別の値へ変更すると、その区分の条件を解除する。APIも申請時の矛盾・未知コード・重複を拒否する。

| 区分 | 選べる条件 |
| --- | --- |
| 撮影 | フラッシュ禁止、三脚禁止、写真のみ・動画不可、指定エリアのみ |
| SNS公開 | ライブ配信不可、クレジット表記、写っている方の掲載許可 |
| 商用利用 | 個人利用のみ |

対象エリアは施設全体／ロビー／展示室／屋外／指定エリア／自由指定から選び、階数・区画などの詳細を原文で補足する。任意の施設名・展示名・場所の固有名を機械的に置換しない。

原文の言語をja／en／zh／koから指定する。言語ごとにルール説明と対象エリア詳細を入力し、「施設側で現在のルール・対象エリアと翻訳を照合しました」を選択する。原文のエリア詳細がある場合、その言語のエリア詳細も必要。翻訳案を自動生成・送信する処理は追加していない。

JSONの追加項目は`areaKind`、`conditions`（コードの配列）、`sourceLanguage`、`translations`（言語コードごとの`text`・`area`・`reviewedDigest`）。定型条件とエリアの定義は`packages/postcheck_rules/lib/multilingual_rules.dart`、公開時の検証・翻訳除外は`cloud/internal/rules/multilingual.go`に置く。

既存の施設管理権限・申請・運営承認を継続する。施設側の確認チェックは翻訳内容の確認であり、翻訳品質を自動検証したことを意味しない。運営も審査画面で定型条件と翻訳の確認状態・文面を確認できる。

## 変更後の再確認

確認状態はルール内容・翻訳先言語・翻訳文・翻訳エリア詳細に結び付ける。ルールのハッシュには施設名・イベント・住所・座標・公式サイト・対象エリア・原文言語・原文・出典URL・可否・条件・登録ワード・解禁日時・有効期限・配信範囲を含む。入力欄の並べ替えだけで意味が変わらない条件・登録ワードはソートする。

`reviewedDigest`は上記の内容と翻訳先言語・翻訳内容をSHA-256で束ねた識別子。電子署名や第三者の翻訳認証ではない。権限確認は既存の施設委任・担当者招待、公開承認は既存の運営審査で行う。DartとGoはUTF-8バイト長付きの同じ形式を使用し、Unicode・URL・座標・時刻を共通テストデータで照合する。

変更により確認状態が古くなった翻訳は管理画面の下書きに残し、公開APIから除外する。翻訳文だけを変更して古い確認値を使い回しても配信しない。申請・承認前は従来の公開スナップショットを保つ。再確認した版を承認すると新しい翻訳を配信する。

## アプリの表示

- 可否と、その可否に対応する具体的な定型条件を選択言語で表示する。
- エリアの種類は同梱文言、詳細は施設が確認した翻訳を表示する。
- 原文の言語を選択している場合は原文を説明として表示する。それ以外は、その言語の確認済み説明だけを表示する。
- 翻訳がない・未確認・古い場合は「この言語の確認済み説明はありません」と案内し、原文と現場の案内を確認するよう促す。他言語の翻訳を確認済み説明として流用しない。
- 原文は展開して確認できる。従来の「未確認は許可を意味しません」と有効期限表示も維持する。定型条件の一覧だけで全条件を網羅したとは扱わない。
- 将来の未知条件を古いアプリが受け取った場合、表示できない条件があることを明示する。

従来データは原文言語ja・自由指定エリア・定型条件なし・翻訳なしとして読める。既存の自由記述から条件やエリアの種類を勝手に推定しない。施設ルールをOFFにした場合も基本チェックは継続する。

## 外国語の操作改善

文章を隠した後の置換文字を選択言語に対応させた：日本語「［非表示］」、英語「[Hidden]」、簡体字「［已隐藏］」、韓国語「[숨김]」。投稿文全体や元の引用を翻訳する機能ではない。変更を適用済みの投稿文はその時点の文字列として保持する。

中国語の「尚未发布／内部资料」、繁体字の「尚未發佈／內部資料」、韓国語の「미공개／대외비／출시 예정」などを告知・機密の確認候補に追加。短い固定表現による補助であり、意味の網羅的な理解や検出保証ではない。
