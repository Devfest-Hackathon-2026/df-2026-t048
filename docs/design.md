## 体験の中心

**素材を用意する → 写真を見ながら確認・修正する → 仕上がりを見て共有する。**

写真選択を主な入口にし、カメラもすぐ使える配置にします。結果一覧・個別確認・範囲編集を独立した画面巡回にせず、写真の枠と下部カードを連動させるひとつの作業画面にまとめます。写真・投稿文のタブで対象を切り替えます。

「隠す」と「そのまま使う」は同等の選択肢。必要な情報だけを隠し、表情や公開する内容を残せることを重視します。小さな修正のたびに全文チェックを繰り返させず、変更をまとめて再チェックする案です。ただし編集時の旧結果無効化・未確認での書き出し禁止は維持し、再確認の完了前に完了表示を出しません。

[発表方針](presentation-strategy.md)に沿い、最終画面は加工後の写真と投稿文を主役にします。炎上スコア・安全保証・自動投稿は加えません。

## 構想と実装の境界

撮影中警告は[全体要件](requirements.md)に沿って実装。V4の09はデザインの基準で、実装・検証状態は[実装記録](implementation-v4.md)を参照。撮影後は採用した静止画を改めてチェックします。

2026-11-08の撮影UI更新：ライブ映像は画面の端まで中央基準で拡大表示し、独立したヘッダー・下部操作パネルは置かない。閉じる・フラッシュは上部、白い丸のシャッター・写真選択・前後切替は下部へ映像に重ねる。操作ボタンのみSafeAreaを尊重し、短い注意はシャッターの上に表示する。検出枠も映像と同じ拡大・切り抜き座標を使う。円形の撮影操作は、通常画面の角丸ボタン規則の例外とする。

ライブ表示では画面比率に合わせて写真の端が一部見えなくなるため、撮影後の採用画面は「写真全体を確認」として原画像全体を表示する。撮影画像を自動で切り抜かず、画面外だった部分も含めて静止画チェックを行う。

14は現行のモデルファイル追加に合わせ、V3にあった自動ダウンロードの表現を変更しました。V4に沿って画面・状態・編集・再チェックを実装しています。デザイン画像は実機画面のキャプチャではありません。OSピッカーの実際の表示はOSに従います。

実装時は入力保持、古い結果の無効化、共有取消、失敗からの復帰に加え、文字拡大・読み上げ・タップ領域・画面のsafe areaを確認します。[実装状況](roadmap.md)に反映範囲と実測結果を追記してください。

## MATRAICEのDESIGN.mdを使ったUI調整

参照元：`/Users/kawakou/apps/matraice-supabase/DESIGN.md`。参照元のプロジェクトは変更せず、同内容を `docs/design-reference-matraice.md` に保存した。

- ヘッダーは濃紺、本文はチャコール、背景は暖色グレー、カードは白と1pxの枠。
- 主要ボタンは指定どおり #5645D4＋白文字。押下時は #4534B3。シードカラーからの自動生成で色が変わらないよう明示した。
- 副ボタンは黒系の文字とグレーの枠。テキスト操作・リンクは青。タブ・補助表示は薄い青で、薄紫の面を使わない。
- 写真上の確認対象は青の枠・番号。既に「残す」と判断した対象はグレー。撮影中の黄色は写り込み注意の意味に限定。
- 入力欄には通常の枠と紫のフォーカス枠。ボタン・入力欄8px、カード12px、ダイアログ16px。
- 見出しは600、本文14–16px、補足12–13px。開始画面の大きな装飾アイコンを、簡潔な手順カードに置換。
- MDの40–44pxより広めに、主要ボタンの最小高さ48pxを維持。文字拡大時は内容に応じて伸びる。
- フォントはNotion Sans / Inter / 日本語システムsansの優先指定。Notionの独自フォントは同梱・取得しておらず、未導入端末ではシステムフォントへフォールバックする。日本語の製品UI見出しはsansを使用。
