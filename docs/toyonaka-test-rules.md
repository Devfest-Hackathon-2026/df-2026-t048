## アプリで試す

1. アプリの施設・地図画面で「再読込」を押す。
2. 登録施設一覧から「大阪大学 豊中キャンパス【動作検証用】」を選び、「この施設のルールを使う」をONにする。撮影・写真選択の**前**に適用する。手動選択ならキャンパス外でも試せる。
3. 架空の文字・人物模型・ダミーコードを使ったテスト写真を選び、確認候補・根拠・隠す範囲を確認する。生の個人情報や認証QRを使わない。
4. 必要な範囲を利用者が「隠す」で選び、書き出し画像を拡大して確認する。人物の体や板面全体など候補範囲が不足する場合も記録する。
5. 同じ条件で施設ルールをOFFにして**新しく**写真を解析し、施設ワードの根拠がなくなる一方、顔・文字などの基本チェックが継続することを比較する。

自動近接適用は現在、代表地点から500m以内が対象。有効な測位と施設一覧がそろえば初回は即時選択し、別施設への切替は独立した測位2回で確認する。キャンパス全域を囲う設定ではないため、今回の試験は手動選択を推奨する。写真は撮影時の施設スナップショットを使うため、既存の解析結果をルール切替だけで再判定したと扱わない。
