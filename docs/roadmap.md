## 今回の追加実装と検証

1. LocationPortと近接判定、候補の精度・鮮度・揺れ対策を追加。距離しきい値は要件の仮置きを実機で調整する。
2. 実装・テスト済み：自動ON、施設ごとの明示OFF維持、手動選択優先、基本チェック継続。
3. 実装・テスト済み：撮影時の適用版を下書きに保持。移動では他施設へ変更せず、公開停止・改版では旧チェックを無効化。過去写真への適用は明示確認。
4. iOSのMapsキー設定と実表示は利用者確認済み。約5m移動目安の測位・地図追従を追加。実GPSでAC-17〜25を検証する。一般利用者の認証・復元は追加予定なし。組織限定配信は後続扱い。

## 既存機能の継続検証

1. iPhoneで前後カメラ、撮り直し、ライブラリ取消、権限拒否/復帰、写真保存、共有取消を確認する。ライブの性能と位置合わせは条件付きで実測する。
2. [比較実験計画](validation-plan.md)で手動確認とアプリの見落とし・修正完了・不要修正・時間を比較する。機能テストを効果検証の代わりにしない。
3. 一般利用者のログイン・クラウド復元は追加予定から外す。旧接続コードは保持するが、有効化・配置・2アカウント/2端末での復元検証は予定しない。同期・復元の必要性が生じた場合に改めて判断する。
4. 指定Google Cloud実行基盤の大会条件は、Cloud Runコードがあるだけでは達成と扱わない。実際の配置とアプリからの利用が必要。
5. クリエイティブカテゴリの説明・デモ・実測結果を整える。カテゴリの運営適合確認は未了。運営への連絡・公開・提出はまだ行っていない。
