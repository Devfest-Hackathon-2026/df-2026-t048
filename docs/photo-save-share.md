# 写真の保存・SNS共有（2026-11-08）

撮影・写真選択 → 確認と編集 → 必要なら再チェック → 「仕上がりを見る」から利用する。

- **写真に保存**：iPhoneの写真ライブラリへ編集済みPNGを追加。写真追加の許可が必要。拒否時は設定への導線を表示し、許可後に再試行できる。保存完了が返った場合だけ完了メッセージを出す。
- **ファイルに保存**：OSの保存先選択画面で、端末内・iCloud Drive等の利用可能な保存先を選ぶ。日時付きPNG名を提案。キャンセルは失敗として扱わず、完了メッセージも出さない。
- **SNS・その他に共有**：iOS標準共有シートへPNGと投稿文を渡す。インストール済みで画像共有に対応するSNS等から利用者が選ぶ。SNS固有の投稿APIは使わず、最終投稿は共有先で行う。共有シートを閉じただけで「投稿完了」と表示しない。
- **投稿文をコピー**：文章を受け取らないSNSの場合に利用者が貼り付けられる。

未確認・未反映の編集がある場合は出力しない。書き出しは編集中の元写真ではなく、適用・再チェック後の写真から作成。新規PNGへ画素を転記し、EXIF・GPSを引き継がない。写真と投稿文をサービス運営側のサーバーへ送る処理は追加しない。共有やiCloudへの保存は利用者が選んだ先に渡す操作。

`FileSavePort`を追加し、保存先選択は`ShareExportAdapter`のfile_picker実装へ分離。写真保存は既存のiOS Photosの完了コールバック、SNS共有はshare_plusを使用。

iOSリリースビルド成功。接続中のiPhoneへ更新版をインストール済み。

検証：静的解析問題なし。既存65件と保存先追加の2件が通過。写真・ファイル・共有の3経路に黒塗り済みの画素が渡ること、保存キャンセル、権限拒否と再試行をテスト。実際の写真ライブラリ・Files・各SNSでの受信操作はiPhone上での確認が必要。Androidの写真ライブラリ保存ネイティブ実装は今回追加していない。
