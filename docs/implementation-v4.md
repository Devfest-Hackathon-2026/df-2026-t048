## 追加・変更

- 写真選択を主入口にしたホーム、カメラ入口、サンプル、文章のみの入口。
- 下書き → 同じ写真で確認候補を見る → 残す/隠す → 修正後再チェック → 仕上がり → 保存/共有。
- 写真/文章のタブ、候補番号、残件数、チェック中のキャンセル、候補なし・AI利用不可・部分失敗の説明。
- 手動マスク、ピンチ拡大、範囲の四隅調整、範囲編集のUndo/リセット/キャンセル、文章の編集、修正前の下書きへの復帰。
- iPhone縦向きカメラのメモリ上のフレーム認識、枠と短い警告、カメラ切替、フラッシュ、撮影/撮り直し/採用、写真ライブラリへの切替、権限設定への案内。
- 企業モードの必須非表示ルール。中央管理ではなく、端末内で変更できる試作。
- 初期オフの個人学習。明示選択した判断を種類別に集計し、3回以上・75%以上一致で提案。生データは学習履歴に保持しない。ユーザー操作で提案を適用し、企業ルールを優先する。
- モデル追加・削除確認、登録ワード、学習リセット、設定の保存。
- Firebase Google/Appleログイン、クラウド保存/復元/削除の画面とアダプター。実環境が未設定の場合は操作を有効化せず、未接続と表示。
- Cloud Run向けGo API、Firestore/KMSアダプター、AES-GCMエンベロープ暗号化、UID単位の認可、更新競合防止、許可リスト、復元前の検証・設定の一括置換。

## 実装上の選択

V4画像はデザインの基準。全画面を別ルートに増やすのではなく、確認中/候補なし/部分失敗/完了は同一ワークスペースの状態として実装した。ライブラリはOS標準UI。写真保存と共有はOSの権限・共有先に従う。

Flutter/Dartのdomain・applicationをSDKから分離し、SettingsPort、PhotoLibraryPort、PhotoSavePort、CloudBackupPort等を追加。Goの中核もGoogle SDKから分離。撮影はカメラビューを持つ入力アダプター。

Firebase/GoogleSignInとCocoaPods版ML KitのGoogle共通ライブラリがSwiftPM経由で二重リンクされるため、公開ブリッジ3パッケージをライセンス・出典付きでローカルに保持し、SwiftPM manifestのみ無効化してCocoaPodsへ統合した。LiteRT-LMはSwiftPM。詳細は`postcheck/vendor/README.md`。

## 残る検証・境界

- ライブカメラの実景での検出精度、枠の一致、前後カメラ、権限拒否、復帰、5分連続稼働、P95時間は実測が必要。設定した750ms/2秒は実装値であり精度・速度の実測ではない。
- Androidのライブ推論は無効。Android実機での他機能も今回未検証。
- 動画、複数写真、直接SNS投稿、企業の中央管理・改変防止、個人識別、Gemmaの追加学習は含まない。
- クラウド実配置は明示的に延期。大会のCloud実行基盤条件をコードだけで達成したとは扱わない。
- ハッカソンの効果検証実験は別作業。今回の機能テストをユーザー実験や有効性の測定と呼ばない。

## 撮影UIの全画面化（2026-11-08追記）

- ライブプレビューを画面いっぱいに拡大し、上部の閉じる・フラッシュ、下部の白い丸シャッター・ライブラリ・前後切替を重ねた。注意表示も映像上に配置。
- `CameraViewport`で映像と検出枠に同じ中央基準のcover変換を適用。枠線は拡大率で太くならない。撮影後は原画像全体を表示し、採用前に端まで確認できる。
- 静的解析・22件のテスト通過。追加2件では縦長・横長表示領域に対して、余白なし・縦横比保持・検出枠との座標一致を確認。iOS Releaseビルド成功。
- この変更版はiPhone再接続後にインストール・起動成功。全画面カメラの実景での目視確認は未実施。以前のカメラ表示確認とは区別する。[検証記録](../output/postcheck-camera-fullscreen-verification/summary.json)。

## iPhone 17 Pro内カメラの回転補正（2026-11-08追記）

- 利用者から「内カメラへ切り替えると横向きのまま」と報告。camera_avfoundation 0.11.1の固定90度指定と、新しい前面センサーの取り付け方向の違いを確認し、AVFoundationへ撮影方向を指定する互換パッチを追加。詳細・非推奨APIの制約は[vendorの記録](../postcheck/vendor/README.md)を参照。
- プレビューの縦横比はOCR完了を待たず、実フレームの寸法を受け取って更新する。カメラ切替の連打を処理中に止め、古いセッションのフレームを破棄する。
- Flutter静的解析・既存22件テスト、iOS Releaseビルド通過。接続中のiPhoneへインストール・起動成功。センサー方向はFlutterテストでは検証できない。2026-11-08、利用者が内カメラの映像が縦向きへ戻ったことを確認（直前の「まだ横向き」という報告は訂正）。検出枠の位置・撮影後の写真の向き・切替と復帰の繰り返しは未確認。[検証記録](../output/postcheck-front-camera-verification/summary.json)。
