# 確認ルール：指摘する項目のON/OFF（企業モードの削除）

2026-11-10 利用者指示。2026-11-08 承認の「企業モード」より、この指示を優先する。

## 仕様

- 設定画面「確認ルール」から「個人／企業」の切り替えを削除し、企業モード（必ず隠す対象、黒塗り固定、「残す」不可）をなくした。
- 代わりに、アプリが指摘できる項目すべてを ON/OFF の一覧で表示する。初期値はすべてON。
  - 連絡先、登録ワード、写り込んだ文字、人物、告知のタイミング、内容の確認（AI）
  - パソコン・スマホ、ホワイトボード、お酒（ワイングラス）、本・資料、額縁、ポスター
- ONの項目は、撮影中（ライブ）と撮影後の確認で指摘する。OFFの項目は候補から外す。
- 施設ルールに該当する候補（`ruleEvidence` を持つもの。施設の登録ワード・施設ルールとの照合）は、OFFでも指摘する。「利用者ルールと施設ルールのどちらかで禁止されていれば指摘する」ため。
- 施設ルールは、従来どおり自動適用の範囲内で一番近い1施設だけを適用する（`nearby_rules.dart`）。
- 1つの候補に複数の根拠がまとめられている場合（例：同じ文字に連絡先と登録ワード）は、どれか1つでもONなら表示する。

## 実装方式と制約

- 検出（OCR・顔・物体検出モデル）はすべて実行し、最後にOFFの項目を外す方式。速度・発熱は変わらない。
- 「必要な検出だけを動かす」方式は、約18〜24時間の作業と見積もったため、今回は採用しない（調査結果は会話記録）。
- 施設ルールで物体の種類（例：ホワイトボード禁止）を指定する項目はまだない。

## コード

- `lib/domain/preferences.dart`：`CheckTarget`（項目一覧と候補からの対応）、`ReviewPreferences.disabledTargets` と `shows()`。
- `lib/application/preferences_codec.dart`：新形式の保存。以前の `mode`・`requiredKinds` を含む設定も読み込める。企業モードで学習した選択回数は破棄する。
- 撮影後：`PostCheckController.findings` で除外。撮影中：`LiveCameraPage` に設定を渡して除外。
- 設定画面：`settings_page.dart` の確認ルールのパネル。
