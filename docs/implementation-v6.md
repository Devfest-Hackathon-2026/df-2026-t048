# V6実装記録 — 近くの施設ルールを自動適用

2026-11-08。要件v0.4の方針をFlutterアプリへ反映。V5の管理Web・Go APIを基礎として維持し、スマホ側の自動候補とON/OFFを追加した。Places APIは使わず、Google／Appleログイン・組織限定配信・クラウド復元の利用導線は後続へ延期。

## 今回実装した体験

- ホームと全画面カメラに、推定施設名・ルールON/OFF・施設変更・原文を表示。施設なし・OFF時も顔／連絡先等の基本チェックを継続する。
- OSの位置情報は利用中だけ取得。初回は説明後に許可を要求し、拒否・取得失敗でも写真チェックを使える。公開施設一覧を匿名取得し、距離は端末内で計算。位置履歴は保存しない。
- 精度50m以内・60秒以内の位置を対象に、100m以内の同候補を連続2測位すると初期ON。15秒ごとに測位する。150m圏外で30秒経過すると解除し、近くの別施設へは25m以上明確に近い場合に切り替える。これらは実測済みの保証値ではなく検証用の初期値。
- 利用者がOFFにした施設は、位置更新・離脱と再進入でONへ戻さない。明示ON・施設の手動選択を優先し、「自動に戻す」で抑制を解除する。状態はセッション内のみ。
- 撮影不可のルールが適用中ならカメラに入る前に案内。プレビュー中に適用された場合も撮影を停止し、原文・施設変更・OFFで訂正できる。OFFは撮影許可の取得を意味しない。
- 撮影時の施設・版を写真の下書きへ保持し、移動で別施設へすり替えない。ライブラリの過去写真には明示確認して適用。撮影画像へGPS座標を追加しない。
- 前景で約1分ごとに公開版を再取得。公開停止・期限切れ・改版が確認できたら旧チェックを無効化する。失敗時は同セッションの版と取得時刻を表示して「最新未確認」と区別する。即時プッシュと永続キャッシュはない。
- 解析中の公開停止や施設切替では古い非同期結果を捨て、再チェックを要求。修正済みのマスクを新しい下書きへ確定してから結果を更新する。
- Maps未設定時は一覧・QR・基本チェックが使える。地図の接続口は維持し、設定後に現在地付近と自前登録施設を表示する。

## デモの確認手順

`RULE_API_URL` 未設定の通常ビルドは、架空施設を明示したデモ。

1. ホームで「架空の施設に近づく」を押す。施設名とルールONになる。
2. OFFにする。基本チェック継続の表示を確認する。
3. 「施設から離れる」→「架空の施設に近づく」。OFFが維持される。
4. 明示的にONに戻し、カメラ・架空の名札・写真確認を試す。
5. 「自動に戻す」から実GPSへ戻せる。サンプル施設の座標を実際の現在地へ移動する処理はない。

デモ操作は合成位置で近接判定を動かすもので、実GPS測定ではない。「施設から離れる」はデモの待ち時間を省き、離脱状態へ直接進める。実測位の30秒猶予とは区別する。

## 追記 — 現在地の5m移動目安の更新（2026-11-08）

利用者からiOSの地図表示ができたと確認済み。その後の依頼で、現在地更新を追加した。

- LocationPortへ測位ストリームを追加。Geolocatorの `distanceFilter: 5` と高精度要求を使う。iOSはバックグラウンド更新を明示的に無効化し、常時位置情報権限の要求もコンパイル設定で外した。
- 前景では初回位置取得＋移動イベントを購読。静止・更新停止時は15秒周期で補助取得する。位置が更新されるたびに公開APIを呼ぶ構成ではなく、施設との距離は引き続き端末内で照合する。
- 地図はNearbyControllerの同じ位置情報を購読し、青い現在地ピン・精度の目安の円・状態表示を更新する。施設が0件でも地図を表示可能。新たなGeolocator購読を地図画面だけで重複開始しない。
- 約5m移動で地図の表示中心も追従。地図上の指の移動で追従停止し、右下の現在地ボタンで実GPS取得と追従を再開する。デモの架空位置は明示し、同じボタンで実際の現在地へ戻れる。
- 低精度でも有効で新しい位置は精度円付きで表示する。一方、施設の自動適用には精度50m以内・連続2測位・100m/150m・離脱30秒の条件を維持。5m移動ごとに施設を無条件切替しない。
- バックグラウンド・デモ切替・破棄時には購読を解除。停止後の位置応答と、ストリーム更新より古い単発取得結果を破棄する。位置履歴は保存しない。

検証：`flutter analyze --no-pub` 指摘なし、全48テスト通過。今回追加8件は移動による更新とOFF維持、停止・復帰と購読数、遅れた単発位置、デモと実測位の切替、低精度・期限切れ、許可拒否、地図追従の停止・再開、不正な位置を対象とする。数値は架空座標での検証であり、実GPSの5m精度・表示遅延・電池負荷の測定結果ではない。

5mはOSへ渡す更新距離の目安で、GPSの精度保証ではない。精度の改善などによって5m未満の更新が届くことも想定し、地図の位置更新と施設判定を分離している。[Geolocatorの公式仕様](https://pub.dev/packages/geolocator)、[AppleのdistanceFilter](https://developer.apple.com/documentation/corelocation/cllocationmanager/distancefilter)

実機の確認手順：PostCheck →「施設を変更」→右下の現在地ボタン→「現在地を使う」→OSの利用中の位置情報を許可。見通しのよい場所で移動し、青いピン・精度表示・追従を確認。地図を手動で動かしても中心が引き戻されず、現在地ボタンで追従に戻ることを確認する。背景移行・復帰と施設OFF維持も確認する。

5m更新版のiOS releaseビルドは成功し、接続iPhoneの開発版へインストール済み。実際に歩いた際のピン移動・追従・精度・電池負荷は利用者による現場確認が必要。
