# アプリ対応言語の整理（2026-11-09）

利用者の「韓国語と中国語対応をアプリから消す。ポスターの案内だけで十分」という指示を反映。以前の4言語対応方針より本方針を優先する。

## 対応範囲

- モバイルアプリのUI・言語設定・施設ルールの案内・AIへの応答言語指定を日本語／英語に統一。
- 中国語／韓国語の翻訳カタログ、iOS権限説明、対応言語宣言を削除。
- 静止画とライブのOCRを日本語／Latinに統一し、中国語／韓国語の専用OCR依存をiOS・Androidから削除。
- 中国語／韓国語の固定告知キーワードと非表示マーカーの分岐を削除。登録ワードやメール・電話番号のチェックは維持。
- ポスターの中国語／韓国語案内は変更しない。

## 既存データとの互換性

以前に保存した `zh`／`ko` の言語設定は未対応値として扱い、「端末に合わせる」に戻る。端末の優先言語から日本語／英語を選び、どちらもなければ英語を使う。設定画面から日本語／英語を選び直せる。

利用者が入力した文章や施設ルールの原文は、言語にかかわらず保持する。施設データの既存契約を壊さないため、共有パッケージ・API・管理Webの中国語／韓国語データ形式は削除しない。今回の変更はモバイル側の対応言語を絞るもので、外国語の入力を禁止するものではない。

## 検証

- `flutter analyze --no-pub`：問題なし。
- `flutter test --no-pub --reporter compact`：115件成功。
- 旧言語設定 `zh`／`ko` と端末言語の組み合わせで起動・設定画面を確認するWidgetテストを追加。
- 日本語／英語で文章のチェック→非表示→再チェック→プレビューを確認する既存Widgetテストを実行。
- `pod install`：成功。中国語／韓国語専用OCR Podを除去。無関係なGoogleDataTransportのバージョンは10.1.0を維持。
- 分離したキャッシュ内で `flutter build ios --release --no-codesign --dart-define-from-file=config/rules.local.json`：成功。生成したアプリの対応言語は日本語／英語のみで、中国語／韓国語のアプリ権限説明リソースがないことを確認。

実機へのインストールとTestFlightへのアップロードは、この変更では実施していない。
