# Gemmaのアプリ同梱（2026-11-09）

> **2026-11-09最新：インストール軽量化**。Gemmaの同梱を取りやめ、初回起動後のWi-Fi自動取得へ変更。準備中も基本チェックを使える。以下の同梱の記述は履歴。[仕様・検証](fast-install-model.md)。

ユーザー指定により、モデルの別途取得・ファイル追加・USB転送を必要とする方式から、Gemma 4 E2Bをアプリに同梱する方式へ変更した。新規インストールではAI補助を初期ONとし、既存利用者のOFF設定を維持する。端末メモリやモデル実行の可否まで保証するものではない。

## 実装

- Flutterアセットとして画像対応の `gemma-4-E2B-it.litertlm` を明示指定。モデルが未準備なら通常のFlutterビルドは失敗する。
- `scripts/prepare_bundled_model.sh` がMacのキャッシュへモデルを取得し、既存の `download_model.sh` で固定SHA-256を照合する。ソース／ステージングにはGit対象外の参照リンクだけを置く。実際のアプリにはリンク先の実ファイルが入る。
- 旧 `install_model.sh` は転送を行わず、同梱版の起動手順を案内する互換入口へ変更。
- `stage_build.sh` から準備を自動実行する。利用者の初回起動ではモデルのネット取得を行わない。直接テスト・ビルドする開発者は先に準備スクリプトを実行する。
- iOSの `postcheck/model` チャネルが署名対象のApp.framework内にあるモデルのパスを返す。Dartへ巨大なバイト列を渡さず、Documents／Application Supportへのモデル複製も行わない。実行キャッシュは従来どおり書き込み可能なアプリキャッシュへ置く。
- Androidには、初回AIチェック時に同梱アセットを非バックアップ領域へストリーム展開する経路を追加。途中ファイルは削除し、サイズ確認後に切り替える。Androidはモデルの展開先にも容量が必要。ビルド・実機・ストア配布は未検証で、iOSと同等の配布対応済みとは扱わない。
- 設定画面は「Gemma 4 E2B（アプリ内蔵）」と追加操作不要の案内に変更。ファイル追加・モデル削除の操作と、設定ポートの追加・削除APIを廃止。AIのON/OFFと公式モデル・利用条件への導線を残す。日本語・英語・簡体字中国語・韓国語に反映。
- AIがOFFのときはモデルパスの準備も行わない。読み込み・実行失敗時は基本チェックを継続し、クラウドAIへのフォールバックを追加しない。
- 旧版で取り込んだモデルを読み込み元に使わない。旧モデルファイルは自動削除しないため、更新インストール済みの端末では旧ファイル分の容量が残る場合がある。新規インストールでの同梱モデルは1つ。
