# カメラ倍率・場所表示（2026-11-08 更新）

## 操作

- 撮影画面の場所ルールは右上の44pxのボタンに集約。18pxの位置アイコンのみ表示し、施設名・説明の帯は下部から削除。タップすると詳細・ON/OFF・施設変更が開く。
- 有効な施設ルールは水色、期限切れ・未更新は黄色、基本チェックは白。読み上げとツールチップで状態を伝える。撮影不可の警告は残す。
- 倍率ボタンは0.5・1・2の固定表示。拡大・縮小どちらも小刻みに更新し、途中の操作は最新の目標倍率に置き換える。
- iOSの背面はAVFoundationの仮想トリプル／デュアルワイドカメラを優先。広角レンズへの切り替え倍率を1倍として正規化し、超広角〜広角〜ズームを同一セッションで操作する。対応端末ではピンチで1倍を下回れる。
- 仮想カメラがない端末では従来の物理レンズとボタン切り替えへフォールバック。超広角がない端末で0.5倍は表示しない。内カメラも端末の許容範囲内。
- カメラ再初期化時は1倍。最大は端末の上限または10倍。画角変更前の検出枠を破棄し、変更終了後に解析を再開。撮影・破棄は倍率変更の終了を待つ。
- 地図の現在地は青い点＋白い縁＋淡い水色の外周。測位精度の円・施設ピンは維持。

## 検証

- カメラプラットフォームを置換したウィジェットテストで2→1→0.5→2→0.5、同一カメラセッションの維持を確認。
- 44pxの場所アイコン、本文非表示、詳細からON/OFFできることをウィジェットテストで確認。
- iOSリリースビルド成功。実レンズの切り替え時の見え方・検出枠の追従は実機での操作確認が必要。自動テストは光学特性・検出精度の保証ではない。
