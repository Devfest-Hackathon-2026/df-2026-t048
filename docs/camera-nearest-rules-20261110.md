# カメラ見出しの中央配置と最寄り施設ルールの自動選択

2026-11-10の利用者指示に対応。当初100mだった自動選択・適用の半径は、同日の追加指示で500mに変更した。

## 変更

- カメラ上部の「写真」は、右側の場所・フラッシュボタンに対して左側の閉じるボタンが少なく、残りの幅の中央へ寄っていた。左右の操作領域をそろえた中央配置へ変更した。英語・文字拡大・幅320／390でも、ボタンと重ならず画面中央に配置する。ライブ映像と検出枠の中央クロップは既存方式を維持する。
- 従来は初回にも同じ最寄りを独立した測位で2回確認し、GPSより施設一覧の取得が遅れた場合も次の測位まで候補を選ばなかった。最初の有効な測位と公開施設一覧がそろった時点で即時選択するよう変更した。
- 別施設への切替は、500m以内の最寄りが独立した測位で2回続いた場合に行う。従来の25m以上の距離差条件を外し、近接する施設どうしでも安定して最寄りへ切り替えられるようにした。同じ時刻の測位や一覧再取得は確認回数を増やさない。
- 自動適用は500m以内に限定する。圏外で候補の表示が残っていても適用しない。場所のルールの表示で圏外と測位待ちを明示する。
- 手動選択は自動へ戻すまで優先し、明示OFFも維持する。手動選択には500mの自動選択制限を課さない。撮影後の写真に記録した施設を、その後の移動だけで上書きしない。
- 位置情報の許可・有効な測位・有効な公開登録施設が必要。精度50m以下・鮮度60秒以内の既存条件と、拒否・取得失敗でも基本チェックを使える仕様は維持する。写真・文章・OCR・GPS座標を公開施設一覧APIへ追加送信する処理はない。
- 候補表示の解除は550m（自動適用半径＋従来の50mの余裕）・30秒とする。500m圏内で離脱扱いにならないよう調整した。

## 施設ごとの500m範囲を地図へ表示（2026-11-10追加）

- 利用者指示により、有効な公開施設ごとに登録座標を中心とする半径500mの円を追加。淡い水色の半透明の塗りと輪郭を使い、実際に適用中の施設は輪郭と塗りを強調する。OFFにすると強調は外れるが、自動選択範囲の円は残す。期限切れ・組織限定の施設には円を出さない。
- 円の半径は自動適用判定と同じ `NearbyRules.automaticRadiusMeters` を参照。現在地の青い点と測位精度の円は保持し、施設の範囲より手前に表示する。初期ズームは現在地がある場合も14とし、周辺の500m範囲を確認しやすくした。
- 有効な現在地から、いずれかの施設の自動選択範囲内／範囲外を「推定」として日英で表示。低精度では判定保留、未取得・古い位置では範囲内と表示しない。範囲の円は自動選択の対象を示し、重なった施設の同時適用や手動選択・OFFの上書きは行わない。
- 地図の下部に水色の円の凡例を追加。施設一覧パネルをMaterialで描き、一覧行の背景・タップ表示が隠れる既存の問題も修正した。
- `flutter analyze --no-pub`：問題なし。
- `flutter test --no-pub test/venue_map_range_test.dart test/venue_page_test.dart test/nearby_rules_test.dart test/location_tracking_test.dart test/nearby_ui_test.dart`：関連28件成功。地図のネイティブ表示を代替し、実際のGoogleMap Widgetへ渡す円の中心・500m半径・透明度、OFF時の強調解除、約499m／501mの表示、低精度・古い測位・再取得後の円の削除、日本語／英語・幅320px・文字1.4倍でのはみ出しなしを確認。
