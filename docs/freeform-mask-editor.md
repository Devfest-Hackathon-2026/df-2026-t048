# 輪郭マスク・ブラシ編集（2026-11-08）

## できること

- 写真の確認画面で「範囲を隠す」、または検出候補の範囲編集を開く。
- 三角形・四角形・五角形・六角形・八角形を追加。各頂点を独立して動かし、台形や凹形状へ変形。図形内部をドラッグして移動。選択中の辺へ頂点を追加できる（最大16頂点）。
- ブラシでぼかし／黒塗りの範囲を追加。消しゴムでマスクを取り除き、元の写真を表示。太さは下部スライダーで変更する。
- 「拡大・移動」で写真を最大8倍に拡大してから、頂点・ブラシの操作に戻れる。
- 取り消し・やり直し・図形削除。キャンセル時は編集前の内容を保持。
- 効果の種類は確認画面の「ぼかし／黒塗り」を継承。企業モードでは黒塗り。編集画面内で効果の種類は変更しない。
- 「完了」の後、変更を画像の画素に反映して再チェック・保存・共有する。図形の外接矩形全体を塗るのではなく、輪郭の内側だけを加工する。

## 自動の画面輪郭候補

iPhoneの撮影後チェックでは、Googleの機器検出に加えてApple Visionの四角形検出を利用。機器の検出範囲と大きく重なる四角形の四隅を候補として保持する。画面の意味的セグメンテーションではなく、ベゼル・別の四角形を候補にする場合がある。画面の縁を確定したとは扱わず、編集画面で利用者が確認・修正する。

輪郭を取得できない場合は機器の矩形を保持する。撮影中の検出は従来の矩形表示を継続し、重い輪郭処理を毎フレーム追加しない。人物全体の輪郭を自動切り抜きする機能は今回の対象外。

参考：[Apple VNDetectRectanglesRequest](https://developer.apple.com/documentation/vision/vndetectrectanglesrequest)。すべて端末内で実行。

## データと描画

- domainの`PhotoMask`に正規化座標の多角形・ブラシ・消しゴムを順序付きで保持。SDKやFlutterの座標型は持たせない。
- ブラシ直径は画像の短辺に対する比率。縦長・横長の写真でも円形を維持。
- UIはGPUのアルファマスクで指の動きに追従。書き出しは画像処理アダプターが同じ操作列を画素化する。消しゴムは被覆率を減算し、白い描画で代用しない。
- ぼかし強度は画像サイズに対する比率で揃える。出力は新規PNGで、元のEXIF・GPSは含めない。
- 複数の検出候補と手動編集の重なりは、プレビューと出力で同じ順序にする。後から重なるマスクがある場合、個別候補の消しゴムだけではその後続マスクは消えない。全体への追加・消去は「範囲を隠す」で行う。
